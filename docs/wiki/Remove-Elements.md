# Remove Elements

Remove Elements lets you delete unwanted page content directly from the browser.

## How to use it

1. Open Webbender.
2. Enable Remove Elements.
3. Click the element you want to hide.

## Notes

- This is best used for temporary cleanup or inspection.
- Removing content does not persist after a page reload unless you save the page content elsewhere.
