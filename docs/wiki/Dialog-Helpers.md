# Dialog Helpers

Dialog Helpers let you test browser dialog behavior without needing to trigger it manually from code.

## What you can test

- alert dialogs
- confirm dialogs
- prompt dialogs

## How to use it

1. Open Webbender.
2. Open the Dialog Helpers section.
3. Click the button for the dialog you want to trigger.
