# Font Override

Font Override lets you change the typeface used on a page without modifying the underlying site source.

## How to use it

1. Open Webbender.
2. Choose a preset font or enter a custom font name.
3. Apply the selection to the current page.

## Tips

- Use this for readability testing or presentation previews.
- Custom fonts depend on the browser and system availability.
