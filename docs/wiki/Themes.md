# Themes

Themes let you apply visual palettes to the current page for contrast, readability, or presentation purposes.

## How to use it

1. Open Webbender.
2. Choose a theme from the available options.
3. Apply it to the current page.

## Use cases

- improve readability in bright or dark environments
- preview a page in a different visual style
- compare how a page looks with alternate color schemes
