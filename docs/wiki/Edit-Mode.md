# Edit Mode

Edit Mode lets you make webpage text editable in place.

## How to use it

1. Open Webbender from the bookmarklet.
2. Enable Edit Mode.
3. Click the text you want to change.
4. Type the new content.

## Tips

- This is useful for quick content mockups and layout experiments.
- Save or copy anything important before reloading the page.
