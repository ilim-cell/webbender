# Updates

The Updates section helps you check whether a newer version of Webbender is available.

## What it does

- compares the installed bookmarklet version with the latest published version
- surfaces update information in the control panel

## Notes

If a newer release is available, you can reinstall the bookmarklet to pick up the latest behavior and fixes.
