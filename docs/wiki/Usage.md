# Usage

Once the bookmarklet is installed, open any page and click it to launch the Webbender panel.

## Core workflows

- [Edit Mode](Edit-Mode.md) for live text editing
- [Remove Elements](Remove-Elements.md) for deleting page content
- [Font Override](Font-Override.md) for changing typography
- [Themes](Themes.md) for visual styling
- [Dialog Helpers](Dialog-Helpers.md) for testing browser dialogs
- [Updates](Updates.md) for checking for newer versions

## Notes

Webbender is intended for temporary page modification. If you want to preserve changes, save the content or copy it elsewhere before reloading the page.
